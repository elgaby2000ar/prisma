# PRISMA · puzzles de luz

Juego de puzzles de láser para Android y web.

- `index.html`: el juego completo.
- `online.js`: módulo online (Firebase: cuentas, amigos, chat, rankings, trampas).
- `firebase-config.js`: datos del proyecto de Firebase.
- `firestore.rules`: reglas de seguridad de la base de datos (pegarlas en Firebase > Firestore > Reglas).
